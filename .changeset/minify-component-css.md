Component styles ship minified. An app's minifier leaves the CSS inside the components' scripts alone, so they now come without comments and indentation: about 14% less to download, such as 4.8 KB instead of 5.7 KB gzipped for `purrlucent/button` and 95.6 KB instead of 110.9 KB for the whole package.
