# HIG audit: command

Sources: [HIG Search fields](https://developer.apple.com/design/human-interface-guidelines/search-fields) and [HIG Menus](https://developer.apple.com/design/human-interface-guidelines/menus). HIG has no command palette page; a palette is a search field over a list of commands, so these two pages are the closest. Code: `src/components/command/`, `src/components/select/match.ts` (`filterIndexes`), `src/components/input/input.css.ts`, `hig/rules/search-fields.yaml`, `hig/rules/menus.yaml`. The pages were not re-read for this audit beyond the rules already recorded in `hig/rules/`. Nothing was run, so every verdict comes from reading the code and the tests.

Verdicts: **met**, **gap**, **deviation** (deliberate, with a reason), **needs eyes** (a visual judgement for the maintainer). Rows marked "not stated" are platform behavior checked against native controls and the WAI-ARIA editable combobox pattern, not against Apple's text.

## Usage guidelines (for `docs/components.md`, not the component)

- Name the palette: `label` is the accessible name of the field and list (default "Commands"); set `placeholder` to say what can be searched ("Search commands").
- The component does not close anything. In a dialog, listen for `pl-select` and call `dialog.close()` yourself.
- Items stay in the order written; put the most used first, or write them in order of relevance.
- Wording: verb-led titles in title case, with the shortcut in `detail`.

## Findings outside HIG

- Home and End move the active item, so they no longer move the caret in the field. Ctrl+A and Ctrl+E, and the arrows with Left and Right, still do. Chosen because the palette has no other way to jump to the ends.
- `pl-command` is not form-associated: it holds a search query, not a value, and `pl-select` is an action.
- The search glyph and the clear glyph are copies of the ones in `input.ts`; they could move to `behaviors/glyphs.ts`.
- That `autofocus` on the element focuses the field inside a dialog (through `delegatesFocus`) is covered by a test that was written, not run.
