# HIG audit: radio-group

Source: [HIG Toggles](https://developer.apple.com/design/human-interface-guidelines/toggles), radio button parts, read 2026-11-22 (change log: March 29, 2024). Code: `src/components/radio-group/`, `src/components/checkbox/checkbox.css.ts` (shared box styles), `src/behaviors/pressable.ts`, `src/behaviors/roving-focus.ts`, `hig/rules/toggles.yaml` (toggles/7 to toggles/10).

Each guideline is either **library** (the component decides it) or **usage** (the app author decides it, so it belongs in the docs). Verdicts: **met**, **gap**, **deviation** (deliberate, with a reason), or **needs eyes** (a visual judgement for the maintainer).

## Usage guidelines (for `docs/components.md`, not the component)

- Use radio buttons for a set of mutually exclusive options; for several choices at once, use checkboxes (toggles/7).
- Keep a set to about five options. For more, use a select or pop-up button instead (toggles/8). The component does not limit the count.
- For a single on or off setting, use a checkbox, not a lone radio; if a checkbox does not make the opposing states clear, use a pair of radios each labelled with the state it controls (toggles/9).
- For a mixed state, use a checkbox, not a radio.
- Always set `label` on the group; without it the group has no accessible name (`radio-group.ts:108-109`). A `purr-radio` without text has no accessible name either.
- Use radio buttons in the window body, not in a toolbar or status bar.
- In a horizontal row, until the library sets equal spacing, give each radio the same width (the width of the longest label) so the spacing is consistent (toggles/10).

## Findings outside HIG

- The `required` validation message is a fixed English string, "Choose one of these options to continue." (`radio-group.ts:259`), so it cannot be localized. The checkbox has the same issue.
- `purr-radio` and `purr-radio-group` are tested in a browser only; this audit ran no tests, and Home and End behavior was read from code (`roving-focus.ts:95-96`) and not checked against native radios.

## Source of truth

`src/tokens/tokens.css` is the source of truth for sizes, radii, spacing and colors (decided 2026-11-22). `design/visual-spec.md` has no radio section and is superseded where it differs from the tokens.
