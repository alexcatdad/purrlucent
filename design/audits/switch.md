# HIG audit: switch

Source: [HIG Toggles](https://developer.apple.com/design/human-interface-guidelines/toggles), read 2026-11-22 (change log: March 29, 2024). Code: `src/components/switch/`, `src/behaviors/pressable.ts`, `hig/rules/toggles.yaml`.

Each guideline is either **library** (the component decides it) or **usage** (the app author decides it, so it belongs in the docs). Verdicts: **met**, **gap**, **deviation** (deliberate, with a reason), or **needs eyes** (a visual judgement for the maintainer).

## Usage guidelines (for `docs/components.md`, not the component)

- Use a switch for two opposing values that affect state; for a choice from a list, use a select (toggles/1).
- Use a switch for a setting you want to emphasize, for example one that turns a group of settings on or off. For a single ordinary option, prefer a checkbox (toggles/4).
- Don't replace an existing checkbox with a switch (toggles/4).
- For a hierarchy of settings, use checkboxes, or a regular switch for the primary setting with mini switches for the subordinate ones (the library has no mini size yet; see the gap).
- On iOS and iPadOS, use a switch only in a list row; outside a list use a button that behaves like a toggle. The row text then names the setting, so no label is needed. In this library, still give an `aria-label` when there is no visible text (toggles/2).
- Change the on color only if needed, and keep enough contrast with the off look.
- A switch takes effect at once (`switch.ts:6`); don't use it for a choice that waits for a Save or Apply button.
- Use switches in the window body, not in a toolbar or status bar.

## Findings outside HIG

- The `required` validation message is the browser's own, localized one, borrowed from a native checkbox (`nativeMessage`, `src/behaviors/native-message.ts`), per `design/decisions.md` item 6.
- Under forced colors, a disabled and checked switch fills the track with GrayText (`switch.css.ts:178-180`); whether the on state still reads is only tested as "differs from enabled" (`switch.e2e.ts:169`).
