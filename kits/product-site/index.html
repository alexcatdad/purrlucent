Frequently asked questions

Do I need a specific framework?

Purrlucent uses standard custom elements. Use it with plain HTML, React, Vue, or any framework that accepts custom elements.

Can I load components individually?

Yes. Each component has its own entry point, such as purrlucent/button. Import the tokens once and add the components you need.

Can I use it in a commercial app?

Yes. Purrlucent is available under the Apache 2.0 license.
