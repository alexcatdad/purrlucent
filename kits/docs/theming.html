Theme Purrlucent

Apply your app’s palette and let the same components follow the page’s color scheme.

Choose a color scheme

The tokens enable light and dark mode by default and follow the system setting. To specify one scheme for the page, set color-scheme in your stylesheet.

Set an accent color

Override the accent token after importing the default tokens. The component fills, accent text, and focus rings use colors derived from this value.

For details on surfaces, spacing, and styling component parts, see the full theming reference.
